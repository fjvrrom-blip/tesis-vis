Objetivos

Objetivo general — Establecer una metodología para el proceso de diseño urbano-arquitectónico de vivienda de interés social periurbana que integre tecnologías emergentes para la recolección, análisis y traducción de datos cualitativos y conductuales de los usuarios en decisiones de diseño informadas; aplicada al caso de Tlajomulco de Zúñiga, ZMG.
OBJ 01
Desarrollar un serious game multiescalar como instrumento de recolección de datos conductuales y aspiracionales de potenciales usuarios de vivienda social.
OBJ 02
Estructurar una base de datos conductual y definir variables cuantificables para su integración en el proceso de diseño paramétrico.
OBJ 03
Integrar los datos en un modelo paramétrico computacional (Grasshopper / Dynamo) para generar y evaluar variantes tipológicas y morfológicas multiescalares.
OBJ 04
Explorar la integración de sensores IoT, machine learning y realidad aumentada como herramientas complementarias de análisis contextual y validación de propuestas con usuarios.
OBJ 05
Construir un marco teórico que articule los Sistemas Complejos Adaptativos con el diseño computacional y las metodologías de participación a escala habitacional y urbana.
OBJ 06
Proyectar las bases conceptuales de un gemelo digital participativo como evolución futura del sistema metodológico, incorporando retroalimentación post-ocupación.
