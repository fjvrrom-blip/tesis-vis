07

Desarrollo del proyecto

La metodología se estructura en tres fases de alcance real para esta investigación, con proyección explícita hacia dos fases futuras. El serious game es el eje central; el diseño paramétrico potenciado con IA es el traductor de datos en decisiones de diseño.

Fases de la investigación
I
Serious Game · Datos cualitativos
Interfaz lúdica multiescalar
Simulación de escenarios habitacionales donde los usuarios configuran tipologías de vivienda, modifican elementos espaciales y perciben fachadas, espacios públicos y mobiliario urbano en múltiples escalas. Se registran decisiones explícitas (colocar / quitar elementos, cambiar colores y texturas) e implícitas (tiempos de permanencia, rutas, interacción con fachadas). Opera como interfaz accesible que reduce la brecha tecnológica.
Referente: Block by Block · UN-Habitat (2021)
II
Base de datos · ML
Estructuración de variables de diseño
Los datos capturados se sistematizan en variables cuantificables: preferencias tipológicas, gradientes público-privado, umbrales de densidad percibida, patrones de uso de espacios de transición. El machine learning —mediante LunchBoxML en Grasshopper o Python 3 en Rhino 8— detecta patrones en esta base conductual y en las condiciones físico-naturales del sitio en Tlajomulco.
LunchBoxML · Rhino 8 + Python 3 · QGIS
III
Diseño Paramétrico + IA
Modelo computacional de diseño
Los datos y patrones se traducen en parámetros que alimentan un modelo en Grasshopper: tipologías de vivienda, morfología del conjunto, espacios de transición y evaluación de emplazamientos. Raven (el agente IA más integrado del ecosistema Rhino/Grasshopper) potencia la escritura de scripts y la generación de variantes. Wallacei permite optimización multi-objetivo. El resultado deriva hacia BIM para documentación constructiva.
Grasshopper · Raven AI · Wallacei · BIM
Herramientas tecnológicas
Serious Game
Juego serio multiescalar
Instrumento principal. Captura decisiones explícitas e implícitas de usuarios potenciales en simulaciones espaciales interactivas a escala de vivienda, conjunto y entorno urbano.
GH + IA
Grasshopper + Raven + Wallacei
Diseño paramétrico potenciado con IA conversacional para exploración de variantes y optimización multi-objetivo basada en los parámetros conductuales del usuario.
ML
Machine Learning
Detección de patrones conductuales y análisis de condiciones físico-naturales del sitio. Integrado en Grasshopper vía LunchBoxML o Rhino 8 con entorno Python 3.
IoT
Sensores e IoT
Conteo, densidad, permanencia y flujos peatonales como datos cuantitativos complementarios. Integrado como referente metodológico y posible capa de validación en campo.
AR
Realidad Aumentada
Visualización de propuestas sobre el sitio real para validación con usuarios en campo. Reduce la abstracción del modelo digital y facilita la participación comunitaria.
BIM
Metodología BIM
Puente entre el modelo paramétrico y la documentación técnica constructiva. Gestión multidimensional: tiempo (4D), costo (5D), sostenibilidad (7D).
